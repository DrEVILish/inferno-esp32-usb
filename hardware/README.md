# usb-inferno hardware (rev 1)

This folder holds the custom board: USB-C (UAC2 HS, bus powered) and RJ45 (10/100
RMII) on an ESP32-P4NRW32X. The design rationale, the sources of every value, the pin
table, the power budget and the risk list are in
[`docs/40-board-rev1.md`](../docs/40-board-rev1.md).

## Layout

| path | what | generated by |
|---|---|---|
| `usb_inferno.py` | **the schematic** (SKiDL). Every part, net and BOM field | hand-written |
| `lib/gen_lib.py` | custom symbols and footprint: ESP32-P4NRW32X (QFN104), IP101GRI, TPS25200DRV | hand-written |
| `lib/usb_inferno.kicad_sym`, `lib/usb_inferno.pretty/` | KiCad library used by the netlist and the PCB | `lib/gen_lib.py` |
| `kicad/usb-inferno.net` | KiCad netlist | `usb_inferno.py` |
| `bom.csv` | grouped BOM (ref, value, description, MPN, manufacturer, LCSC, LCSC status, footprint, qty, DNP) | `usb_inferno.py` |
| `erc.log` | SKiDL ERC result | `build.sh` |
| `kicad/usb-inferno.kicad_pcb` | 4-layer board: outline, stackup, placed parts, GND/3V3 zones, not routed | `tools/make_pcb.py` |
| `kicad/usb-inferno.kicad_pro`, `.kicad_dru` | net classes and patterns, JLC minimums, custom diff-pair/length rules | `tools/make_pcb.py` |
| `kicad/drc-unrouted.rpt` | `kicad-cli pcb drc` of the unrouted board | `build.sh` |
| `tools/pin_table.py` | prints the U1/U6 pin tables in docs/40 §5 from the netlist | — |

## Regenerate (netlist → PCB)

```sh
# one-time setup (Debian 13): KiCad 9 + libraries, SKiDL in a venv
nice apt-get install -y --no-install-recommends kicad kicad-symbols kicad-footprints
python3 -m venv /opt/usb-inferno/work/venv-hw && /opt/usb-inferno/work/venv-hw/bin/pip install skidl
# KiCad global library tables (normally created by KiCad's first-run wizard):
mkdir -p ~/.config/kicad/9.0 && cp -n /usr/share/kicad/template/*-lib-table ~/.config/kicad/9.0/

hardware/build.sh        # gen_lib -> SKiDL (ERC, netlist, BOM) -> pcbnew placement -> DRC
```

`tools/make_pcb.py` **overwrites** `usb-inferno.kicad_pcb`. Once the human layout pass
starts, stop running it. Push schematic changes into the routed board with
pcbnew *File → Import Netlist* (`kicad/usb-inferno.net`, match by reference).

## Status

- **ERC (SKiDL):** 0 errors, 0 warnings. SKiDL emits a netlist, not a `.kicad_sch`, so
  KiCad's schematic ERC does not apply. The remaining "fp-lib-table not found"
  messages come from SKiDL probing for KiCad 6/7/8/10 configurations and are harmless.
- **PCB DRC (unrouted):** 0 clearance, courtyard or edge errors. All violations left
  are expected for an unrouted board: unconnected items, silk overlaps of the staged
  passives, and the REF_CLK length rule (no tracks yet).
- **Routing: not started.** See docs/40 §18 for the list of what remains.

## Verified vs assumed

Verified against a cited document during this pass:
- P4 pins, power domains, rail ranges, decoupling, the v3.x pin 54 / DCDC / DP
  changes, strapping, CHIP_PU timing, flash voltage, crystal ([DS], [HDG], [REV3], [PCN]).
- IP101GRI pinout, package (QFN32 **4×4**), straps, 50 MHz-input mode, centre-tap
  handling, reset timing ([IP]); [WS] wiring for the same PHY.
- TPS25200, TLV62569 and TPD2EUSB30 pinouts and key values (TI data sheets).
- LCSC numbers marked `checked` in `bom.csv`.

Assumed or UNVERIFIED (details in docs/40 §17):
- the QFN104 land pattern (derived from the package drawing, not an Espressif
  footprint);
- stackup thicknesses and impedance geometry (closed-form models, not the JLC
  calculator);
- ESP32-P4NRW32X availability at LCSC/JLC (none found);
- LCSC numbers marked `recall`/`TBD`;
- HR911105A LED polarity (taken from the KiCad symbol);
- current estimates beyond the datasheet figures.
